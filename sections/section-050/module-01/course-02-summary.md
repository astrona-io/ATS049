# Summary

Binary operators combine values or select populations according to both numerical and label semantics. Vector arithmetic requires matching series, while comparison filtering and bool results describe different output models.

On and ignoring define matching dimensions, and group modifiers require a unique side for many-to-one relationships. Missing matches and zero denominators need deliberate handling; permissive syntax cannot repair an undefined measurement relationship.
