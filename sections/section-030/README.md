# Aggregating over time

This section covers aggregating over time. It develops aggregating Samples Across Time Windows through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains include an intermediate checkpoint before the final review.

## Learning Outcomes

- Distinguish per-series time aggregation from cross-series aggregation.
- Choose avg, max, count and present-over-time functions appropriately.
- Explain sample weighting and missing observations.
- Interpret subqueries and derived expression windows.
