# Selecting Data

This section covers selecting Data. It develops selecting PromQL Data And Evaluation Time through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains include an intermediate checkpoint before the final review.

## Learning Outcomes

- Distinguish instant vectors, range vectors and range queries.
- Interpret equality and anchored regular-expression matchers.
- Explain lookback, staleness, offset and explicit evaluation time.
- Choose selectors whose labels match the intended population.
